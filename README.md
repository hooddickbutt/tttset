# Ansemmas

Static recreation of the [Ansemmas](https://ansemmas.fun/) landing page: the same layout, copy, images, snow, and copy-address button.

Plain HTML, CSS, and JavaScript. Vite only serves and builds it.

## Run locally

```bash
npm install
npm run dev
```

Open http://127.0.0.1:47321

## Build

```bash
npm run build
npm run preview
```

The production files land in `dist/`.
